# 方法原理

点光源提供逆平方衰减的入射照度 `E = I / light_scale / r²`。
从光源视角用原生 3DGS alpha 合成学习通量特征及归一化深度的一阶、二阶矩，
用可分离二项式模糊和 2 倍平均池化构造七层光空间图集（512 至 8）。
接收点投影到每层图集并双线性采样，从覆盖率、深度偏差、方差和矩可见性学习阴影修正与传输权重。

最终线性辐射为 `E * (V * rho + V0 * specular + transfer)`：

- `rho`：SVBRDF 头，用八个与光照无关的空间系数组合方向相关 RGB 基底；空间潜码仍允许局部外观自由度。
- `V`：深度矩可见性 `V0` 的 logit 加神经修正，再 sigmoid。
- `specular`：由位置/材质决定权重的半向量 lobes，由几何矩可见性遮挡。
- `transfer`：对多层学习通量的线性加权，表示散射和近邻反弹。

学习法线占据每个高斯 feature 的前三个通道；非方向外观支路使用其 detached 值。
初始化、网络宽度、层序、激活和图集统计量均沿用原实现。
算法代码及详细注释见 [light_atlas.py](../../lisags/models/light_atlas.py)。

该分解不保证唯一物理解；单透视图集要求光源在场景外。像素精修阶段的期望深度在混合表面处存在局限。
